# AI Wellness Companion – SERENITY

## 📌 Project Overview

**AI Wellness Companion – SERENITY** is a survey-driven wellness project designed to explore how an AI-powered assistant can support users with everyday mental-wellness needs.

The project combines:

- Survey data collection
- Data cleaning and anonymization
- Data analysis
- Tableau data visualization
- Python-based decision simulation
- Prompt engineering
- AI wellness companion design

The project was developed using survey responses to understand users' stress patterns, wellness factors, preferred features, trust in AI suggestions, and preferred communication style.

---

## 🎯 Project Objectives

The main objectives of this project are:

- Analyze user stress patterns and wellness factors
- Understand users' interest in an AI wellness assistant
- Identify the most preferred wellness features
- Analyze users' trust in AI-generated wellness suggestions
- Identify the preferred communication tone
- Use survey findings to support the design of the SERENITY wellness companion
- Present the findings through data visualization

## 🔍 Key Insights

The survey analysis produced the following observations:

### Age Group

The majority of survey respondents belong to the **18–22 age group**.

### Stress Frequency

"Sometimes" was the most commonly selected stress frequency among respondents.

### Mental-Wellness Factors

**Studies** were the most frequently selected factor affecting mental wellness in the survey.

Other reported factors included:

- Financial stress
- Sleep problems
- Work pressures
- Social issues

### Interest in an AI Wellness Assistant

Most respondents selected either **"Yes"** or **"Maybe"** when asked whether they would use an AI wellness assistant.

### Preferred Features

**Stress relief exercises** were the most frequently selected feature.

Other preferred features included:

- Mood tracking
- Sleep improvement tips
- Meditation reminders

### Trust in AI

Most respondents selected either **"Yes"** or **"Somewhat"** when asked whether they trust AI for wellness suggestions.

### Preferred Communication Tone

**Friendly** was the most preferred communication style among the respondents.

## 🤖 SERENITY – AI Wellness Companion

**SERENITY** is the AI wellness companion concept developed as part of this project.

The project presentation describes an agentic workflow based on:

**Think → Decide → Act**

### Think

The system receives user input and considers:

- Sentiment
- User intent
- Context
- Previous information or memory

### Decide

The system can:

- Classify the type and severity of stress
- Match the situation with relevant knowledge
- Select an appropriate response
- Personalize the response

### Act

The system can provide:

- Empathetic responses
- Coping techniques
- Reminders
- Wellness suggestions
- Appropriate escalation for critical situations

This workflow is described in the project presentation.
